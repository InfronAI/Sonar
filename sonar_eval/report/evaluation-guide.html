Run one combination from the CLI

From the project root, choose an agent with --cli, a provider with --provider, an exact model ID with --model and a task or suite with --suite. Run doctor to check the selection and installed images. Use the same arguments with run to start the evaluation.

Connect Pi to your own provider

Replace the example model ID and gateway URL with your provider’s values. Set TEAM_MODEL_KEY in the launch environment. Pi uses a Chat Completions endpoint for this example.

./sonar doctor --cli pi --provider team-gateway --model team/model-v2 \
  --base-url https://gateway.example.com/v1 --api-key-env TEAM_MODEL_KEY \
  --suite suites/datasets/sql-analytics
./sonar run --cli pi --provider team-gateway --model team/model-v2 \
  --base-url https://gateway.example.com/v1 --api-key-env TEAM_MODEL_KEY \
  --suite suites/datasets/sql-analytics

Compare several combinations with JSON

Save the template as configs/my-eval.json. It compares Pi and Claude Code on the same Infron model. Each agent attempts every task in the SQL suite twice. For Infron access, use ./sonar set-key infron once in this workspace.

  • suite is relative to the JSON file. Use ../suites/all-tasks.json for all 102 tasks in v5. The default matrices use ../suites/all-tasks-v4.json.
  • Choose ../suites/all-tasks-v3.json for the original 60 deterministic tasks or ../suites/rubric-tasks.json for the 40 assessed by Infron’s infron/op-5.5. The 100-task v4 baseline includes both. ../suites/quick-14.json selects one task per domain.
  • agents and models form all combinations by default. To select specific pairs, add "pairs": [["glm", "pi"]] using the model ID first.
  • repetitions sets attempts per pair and task. agent_timeout_seconds limits agent execution and timeout_seconds covers the entire trial, including setup and verification.
  • inference sets controls such as max_tokens for supported agents. CLI overrides take precedence. The run saves the resolved values in plan.json.
./sonar doctor --config configs/my-eval.json
./sonar run --config configs/my-eval.json
