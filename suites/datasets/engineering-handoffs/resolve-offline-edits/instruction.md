# Define an offline edit conflict policy

Prepare a product-engineering handoff for reconciling offline edits to a shared reading list.

## Case packet

A tablet renames an item offline while a laptop changes its priority. On reconnect the current server replaces the whole item. Two devices sometimes edit the same title. Device clocks have differed by 11 minutes. A delete followed by a stale edit has resurrected items. Users need a visible explanation for unresolved conflicts.
