# Triage a proposed scope amendment

Prepare a short approval-path memo for a project manager working under fictional procurement rules.

## Case packet

The signed cap is $80k for site A only. A manager emailed a request to add site B for $12k. Rule S requires written amendments signed by both designated officers for any added site. Rule V requires finance review when the cumulative cap exceeds $90k. A $4k credit has been proposed but not signed. Site B work is scheduled for tomorrow.

## Submission

Write your response in English to `/app/submission.md` as plain UTF-8 Markdown (up to 16 KiB). Address the decision-maker, support your reasoning with the supplied facts and identify material uncertainty. Use only this fictional case packet.
